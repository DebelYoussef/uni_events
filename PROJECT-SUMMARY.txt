PROJECT OVERVIEW
================================================================================
A complete PHP-based University Events Management System implementing:
- User registration with role selection (Student/Organizer/Admin)
- Secure login with session-based authentication
- Role-based access control and navigation
- Professional UI with responsive design
- Database schema for events, registrations, attendance, and certificates

TECHNOLOGY STACK
================================================================================
✓ Backend: PHP 7.4+
✓ Database: MySQL
✓ Frontend: HTML5, CSS3, Vanilla JavaScript
✓ Server: Apache (XAMPP/Laragon/WAMP)
✓ NO Node.js server, NO Next.js framework

HOW TO USE THIS PROJECT
================================================================================

1. SETUP DATABASE
   - Import database.sql into MySQL
   - Create database "uni_events"
   - All tables created automatically

2. UPDATE CONFIG
   - Edit config/database.php with your credentials
   - Update config/constants.php BASE_URL if needed

3. CREATE UPLOADS FOLDER
   - Create public/uploads/ directory
   - Set write permissions

4. RUN APPLICATION
   - Open http://localhost/uni_events/
   - Register a new account
   - Login with credentials
   - Auto-redirect to appropriate dashboard

5. TEST CREDENTIALS
   - Admin: admin@unievents.local / Admin@123
   - Create student/organizer test accounts
